The logo as it appears on each ground: the primary lockup, the mark alone, the favicon and app-icon tiles, and the typographic short form.

**Use** the SVG files under `assets/Logos/` as `<img>`; pick the file by ground (light: `cde-lockup.svg`, dark: `cde-lockup-paper-trace.svg`). Do not inline and recolour; the files carry their own ink.

**Sizes.** App header: lockup at 20 px cap height (the `height="28"` shown here is the SVG's full box). Favicon: `cde-favicon.svg` at 16 to 32 px. Mark alone never below 16 px tall.

**Live text.** When the wordmark must be selectable text (a document footer, a terminal banner), set "CAN DATA EXTRACT" in the `wordmark` style, which carries Martian Mono Bold, uppercase and 0.06 em tracking.

**Don't** place the lockup on a `trace` tile, rotate the mark, draw it in a status colour, draw both channels in `trace`, or change the bit pattern.
